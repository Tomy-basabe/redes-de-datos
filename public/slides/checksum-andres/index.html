Ausencia de NAK
1. Descarta en silencio

El servidor descarta el segmento dañado sin generar NAK ni enviar confirmación (ACK).

2. Emisor retransmite

Al vencerse el temporizador (Timeout) o recibir 3 ACKs duplicados, la PC retransmite el segmento.

Servicios UDP: Windows DHCP :67/68 · Cisco OpenDNS :53
Sin retransmisión L4
1. Calcula y descarta

Verifica el checksum de 16 bits. Si hay error, descarta el datagrama para no procesar datos erróneos.

2. Resuelve la aplicación

Capa 4 no ofrece retransmisiones; la aplicación cliente reintenta la consulta si no recibe respuesta.
